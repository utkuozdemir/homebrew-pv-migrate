# homebrew-pv-migrate

This repository hosts the Homebrew cask of [pv-migrate](https://github.com/utkuozdemir/pv-migrate).

```sh
brew install utkuozdemir/pv-migrate/pv-migrate
```

The fully qualified name is required.
Homebrew loads a cask from a non-official tap only when it is trusted, and installing the cask by its full name trusts exactly this cask.

Do not edit the cask, goreleaser pushes it from the main repository on every release.
For everything else, see the main repository.
